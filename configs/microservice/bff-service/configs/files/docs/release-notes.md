# ✨v0.6.3 有哪些新功能？✨

在此版本中，我们添加了大量新功能、提升了用户使用时的交互体验，并修复了用户反馈的一些问题，希望能为您带来更好的使用感受。

> 💡 **配置提示：** 应用观测中的「调用明细」支持记录完整的请求体和响应体（Request Body / Response Body），该功能通过 .env 文件环境变量 `WANWU_BFF_STATISTIC_RECORD_BODY` 控制（默认 `0` 关闭，设为 `1` 开启）。
>
> - **开启时：** 模型调用、应用调用、API Key 调用的明细记录中将保存整体请求与响应的 JSON 内容。由于会占用大量存储空间，建议定期清理历史明细数据。
> - **关闭时：** 不落库完整请求/响应体，仅记录精简的问答摘要（Question / Answer）。流式响应始终不记录 Response Body。

## 🚀 新功能

- **本体智能体：**
  - 数字员工支持发布，可配置发布范围
  - 支持在应用广场查看并使用已发布的数字员工

- **知识问答：**
  - 支持历史记录保存、查看、删除

- **消息中心：**
  - 新增消息中心，可提示应用上架、模型上下架、知识库上架

- **知识库：**
  - 升级分段内容搜索

- **OpenAPI：**
  - 新增知识库子分段编辑接口，支持子分段接口OpenAPI返回新的分段ID

- **应用观测：**
  - 升级统计看板，支持按照我发布的、我使用的维度，查看模型、应用统计。
  - 支持模型、智能体应用排行
  - 支持查看模型、应用、API的调用明细。


## 📈增强功能

- **智能体：**
