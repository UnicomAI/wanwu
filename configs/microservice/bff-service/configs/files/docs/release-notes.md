# ✨v0.6.2 有哪些新功能？✨

在此版本中，我们添加了大量新功能、提升了用户使用时的交互体验，并修复了用户反馈的一些问题，希望能为您带来更好的使用感受。


## 🚀 新功能

- **渠道管理：**
  - 新增通用智能体-数据分析

- **管理员中心：**
  - 新增产品后台。系统管理员、组织管理员可查看用户创建应用详情。包括模型、资源库、应用开发模块的内容。
  - 组织管理支持选择上级组织
  - 用户管理支持批量删除/移除

- **知识库：**
  - 支持展示文件大小
  - 下线url文件解析


## 📈增强功能

- **通用智能体：**
  - 优化沙箱启动速度

- **组织管理：**
  - 默认折叠到二级组织


## 🛠️ 错误修复

- **智能体：**
  - 智能体Openapi调用报错
  - 智能体上传文件显示大小有误
  - 接口报错后，重新生成未携带上一轮的文件信息

- **知识库：**
  - 知识库与平台接口交互安全升级，修复无认证外部接口带来的安全风险漏洞

- **本体智能体：**
  - 修复万悟中文账号登录访问数字员工报错问题

- **渠道管理：**
  - 修复微信回复乱码问题
  - 修复图片显示问题
