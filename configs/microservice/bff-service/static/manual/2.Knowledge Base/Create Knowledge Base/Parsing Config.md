# 解析方式Configuration

- **文本提取：**适用于所有File，在提取文档文本信息时开启
- **OCR解析：**适用于pdfFile，在解析Image、扫描件文档时开启，需提前在Model Management中接入ocr模型，详见[Model Import Guide-详细版](Model Import Guide-详细版.md)
- **模型解析：**适用于pdf、word、pptFile，在提取标题、图表、公式时开启，需提前在Model Management中接入pdfDocument Parsing模型，详见[Model Import Guide-详细版](Model Import Guide-详细版.md)
