Agent API
========



## Agent创建对话API

AgentApp支持会话持久化，可将之前的聊天记录作为上下文进行回答，可适用于聊天/客服 AI 等。

### 请求Interface

| Type                 | Instructions                                                 |
| -------------------- | ------------------------------------------------------------ |
| 方法                 | Http                                                         |
| 请求URL              | 按照App实际API根地址，例如：<br />`http://localhost:8081/service/api/openapi/v1/agent/conversation` |
| 字符编码             | UTF-8                                                        |
| 请求Type             | POST                                                         |
| 鉴权方式(header参数) | `Authorization: Bearer {API Key}`                            |
| 请求格式             | `Content-Type: application/json`                             |
| 响应格式             | 非流式：`Content-Type: application/json`<br />流    式：`Content-Type: text/event-stream` |

### 请求参数

| Parameter | Required | Type   | Instructions |
| --------- | -------- | ------ | ------------ |
| title     | Yes       | string | 对话标题     |

### 响应参数

| Parameter | Type   | Instructions                                                 |
| --------- | ------ | ------------------------------------------------------------ |
| code      | int    | Status码，用于表示请求Success或具体的ErrorType                     |
| msg       | string | 提示信息，通常用于提供关于code的详细解释或请求Success的Confirm信息 |
| data      | array  | 当前响应文本，包含了根据UserInput和Knowledge Base搜索得到的答案       |

#### data

| Parameter       | Type   | Instructions       |
| --------------- | ------ | ------------------ |
| conversation_id | string | 当前响应文本片段ID |

### 调用Example

```shell
curl -k --location 'http://localhost:8081/service/api/openapi/v1/agent/conversation' 
--header 'Content-Type: application/json' \
--header 'Accept: application/json' \
--header 'Authorization: Bearer <API Key>' \
--data '{
    "title": "你好，DeepSeek"
}'
```

### 响应Example

```json
{
    "code": 0,
    "data": {
        "conversation_id": "56"
    },
    "msg": ""
}
```

## Agent对话API

AgentApp支持会话持久化，可将之前的聊天记录作为上下文进行回答，可适用于聊天/客服 AI 等。

### 请求Interface

| Type                 | Instructions                                                 |
| -------------------- | ------------------------------------------------------------ |
| 方法                 | Http                                                         |
| 请求URL              | 按照App实际API根地址，例如：<br />`http://localhost:8081/service/api/openapi/v1/agent/chat` |
| 字符编码             | UTF-8                                                        |
| 请求Type             | POST                                                         |
| 鉴权方式(header参数) | `Authorization: Bearer {API Key}`                            |
| 请求格式             | `Content-Type: application/json`                             |
| 响应格式             | 非流式：`Content-Type: application/json`<br />流    式：`Content-Type: text/event-stream` |

### 请求参数

| Parameter       | Required | Type   | Instructions                                                 |
| --------------- | -------- | ------ | ------------------------------------------------------------ |
| conversation_id | Yes       | string | 历史响应文本片段ID                                           |
| stream          | No       | bool   | YesNo以流式Interface的形式返回Data，默认为非流式。 true为流式，false为非流式 |
| query           | Yes       | string | User提出的问题或提示语                                       |

### 响应参数

| Parameter         | Type   | Instructions                                                 |
| ----------------- | ------ | ------------------------------------------------------------ |
| code              | int    | Status码，用于表示请求Success或具体的ErrorType                     |
| message           | string | 提示信息，通常用于提供关于code的详细解释或请求Success的Confirm信息 |
| gen_file_url_list | array  | 模型生成Output的FileurlList                                    |
| response          | string | 当前响应文本，包含了根据UserInput和Knowledge Base搜索得到的答案       |
| search_list       | array  | 知识增强搜索结果                                             |
| history           | array  | 包含之前对话历史的数组，用于上下文管理                       |
| usage             | array  | token使用量                                                  |
| finish            | int    | 仅在流式返回中有该字段。表示流YesNoEnd，0：未End，1：正常End，2：生成长度导致End，3：异常End，4：命中Safety GuardrailsEnd |

#### gen_file_url_list

| Parameter       | Type   | Instructions |
| --------------- | ------ | ------------ |
| output_file_url | string | OutputFileurl  |

#### history

| Parameter | Type   | Instructions |
| --------- | ------ | ------------ |
| query     | string | 请求文本     |
| response  | string | 模型响应文本 |

#### search_list

| Parameter | Type   | Instructions |
| --------- | ------ | ------------ |
| kb_name   | string | Knowledge Base名字   |
| snippet   | string | 知识内容片段 |
| title     | string | File标题     |

#### usage

| Parameter         | Type | Instructions          |
| ----------------- | ---- | --------------------- |
| prompt_tokens     | int  | Input提示词token数     |
| completion_tokens | int  | Output文本token数       |
| total_tokens      | int  | Input加Output总的token数 |

### 调用Example

#### 流式

```shell
curl -k --location 'http://localhost:8081/service/api/openapi/v1/agent/chat' \
--header 'Content-Type: application/json' \
--header 'Accept: application/json' \
--header 'Authorization: Bearer <API Key>' \
--data '{
    "stream": true,
    "conversation_id": "56",
    "query": "请一句话介绍DeepSeek"
}'
```

#### 非流式

```shell
curl -k --location 'http://localhost:8081/service/api/openapi/v1/agent/chat' \
--header 'Content-Type: application/json' \
--header 'Accept: application/json' \
--header 'Authorization: Bearer <API Key>' \
--data '{
    "stream": false,
    "conversation_id": "56",
    "query": "请一句话介绍DeepSeek"
}'
```
