Workflow API
========



## Workflow运行API

该Interface用于执行指定的Workflow并返回运行结果。

### 请求Interface

| Type                 | Instructions                                                 |
| -------------------- | ------------------------------------------------------------ |
| 方法                 | Http                                                         |
| 请求URL              | 按照App实际API根地址，例如：<br />`http://localhost:8081/service/api/openapi/v1/workflow/run` |
| 字符编码             | UTF-8                                                        |
| 请求Type             | POST                                                         |
| 鉴权方式(header参数) | `Authorization: Bearer {API Key}`                            |
| 请求格式             | `Content-Type: application/json`                             |
| 响应格式             | `Content-Type: application/json`                             |

### 调用Example1

WorkflowQuery成都未来天气

```shell
curl -k --location 'http://localhost:8081/service/api/openapi/v1/workflow/run' \
--header 'Content-Type: application/json' \
--header 'Accept: application/json' \
--header 'Authorization: Bearer <API Key>' \
--data '{
    "city": "成都"
}'
```

## WorkflowUploadFileAPI

该Interface用于执行指定的WorkflowUploadFile并返回FileLink。

### 请求Interface

| Type                 | Instructions                                                 |
| -------------------- | ------------------------------------------------------------ |
| 方法                 | Http                                                         |
| 请求URL              | 按照App实际API根地址，例如：<br />`http://localhost:8081/service/api/openapi/v1/workflow/file/upload` |
| 字符编码             | UTF-8                                                        |
| 请求Type             | POST                                                         |
| 鉴权方式(header参数) | `Authorization: Bearer {API Key}`                            |
| 请求格式             | `Content-Type: multipart/form-data`                          |
| 响应格式             | `Content-Type: application/json`                             |

### 请求参数

| Parameter | Required | Type | Instructions   |
| --------- | -------- | ---- | -------------- |
| file      | Yes       | file | 需要Upload的File |

### 响应参数

| Parameter | Type   | Instructions                  |
| --------- | ------ | ----------------------------- |
|           | string | UserUploadFile返回在oss中的Link |

### 调用Example

```shell
curl -k --location 'http://localhost:8081/service/api/openapi/v1/workflow/file/upload' \
--header 'Content-Type: multipart/form-data' \
--header 'Accept: application/json' \
--header 'Authorization: Bearer <API Key>' \
--form 'file=@/测试.txt'
```
