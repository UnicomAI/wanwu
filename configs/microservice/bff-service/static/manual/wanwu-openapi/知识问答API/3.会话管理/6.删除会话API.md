# 删除会话API

删除整条会话（含全部历史消息）。

> **`clear` 还是 `delete`**：想保留同一会话继续问答用[清空会话历史API](7.清空会话历史API.md)；不再使用用本接口（下次问答前需重新创建会话）。

## 请求接口

| Type | Instructions |
| ---- | ---- |
| 方法 | Http |
| 请求URL | 按照应用实际API根地址，例如：`http://localhost:8081/service/api/openapi/v1/rag/conversation` |
| 字符编码 | UTF-8 |
| 请求类型 | DELETE |
| 鉴权方式(header参数) | `Authorization: Bearer {API Key}` |
| 响应格式 | `Content-Type: application/json` |

## 请求参数

| Parameter | Required | Type | Instructions |
| --------- | -------- | ---- | ---- |
| uuid | 是 | string | 知识问答UUID |
| conversation_id | 是 | string | 会话ID |

## 响应参数

| Parameter | Type | Instructions |
| --------- | ---- | ---- |
| code | int | 状态码，0表示成功 |
| msg | string | 提示信息 |
| data | object | 空 |

## 调用示例

```shell
curl -k --location --request DELETE 'http://localhost:8081/service/api/openapi/v1/rag/conversation?uuid=2004010127610351679&conversation_id=56' \
--header 'Authorization: Bearer <API Key>'
```

## 响应示例

```json
{
    "code": 0,
    "msg": "",
    "data": null
}
```
