# 删除草稿态会话API

删除草稿态会话的问答消息。

- 传 `detail_id`：只删除该条问答
- 不传 `detail_id`：删除整条草稿会话

> 草稿会话尚未创建时直接返回成功（幂等）。

## 请求接口

| Type | Instructions |
| ---- | ---- |
| 方法 | Http |
| 请求URL | 按照应用实际API根地址，例如：`http://localhost:8081/service/api/openapi/v1/rag/conversation/draft` |
| 字符编码 | UTF-8 |
| 请求类型 | DELETE |
| 鉴权方式(header参数) | `Authorization: Bearer {API Key}` |
| 响应格式 | `Content-Type: application/json` |

## 请求参数

| Parameter | Required | Type | Instructions |
| --------- | -------- | ---- | ---- |
| uuid | 是 | string | 知识问答UUID |
| detail_id | 否 | string | 问答明细ID，不传则删除整条草稿会话 |

## 响应参数

| Parameter | Type | Instructions |
| --------- | ---- | ---- |
| code | int | 状态码，0表示成功 |
| msg | string | 提示信息 |
| data | object | 空 |

## 调用示例

```shell
curl -k --location --request DELETE 'http://localhost:8081/service/api/openapi/v1/rag/conversation/draft?uuid=2004010127610351679' \
--header 'Authorization: Bearer <API Key>'
```

## 响应示例

```json
{
    "code": 0,
    "msg": "",
    "data": null
}
```
