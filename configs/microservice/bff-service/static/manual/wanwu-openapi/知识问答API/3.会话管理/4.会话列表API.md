# 会话列表API

获取指定知识问答的**已发布会话**列表，按创建时间降序分页返回。草稿态会话不在此接口范围内（草稿态每个应用只有一条会话，参见[草稿态会话历史API](8.草稿态会话历史API.md)）。

## 请求接口

| Type | Instructions |
| ---- | ---- |
| 方法 | Http |
| 请求URL | 按照应用实际API根地址，例如：`http://localhost:8081/service/api/openapi/v1/rag/conversation/list` |
| 字符编码 | UTF-8 |
| 请求类型 | GET |
| 鉴权方式(header参数) | `Authorization: Bearer {API Key}` |
| 响应格式 | `Content-Type: application/json` |

## 请求参数

| Parameter | Required | Type | Instructions |
| --------- | -------- | ---- | ---- |
| uuid | 是 | string | 知识问答UUID |
| searchText | 否 | string | 按会话标题模糊筛选 |
| pageNo | 是 | int | 页码，从 1 开始 |
| pageSize | 是 | int | 每页条数，从 1 开始 |

## 响应参数

| Parameter | Type | Instructions |
| --------- | ---- | ---- |
| code | int | 状态码，0表示成功 |
| msg | string | 提示信息 |
| data | object | 响应数据 |

### data

| Parameter | Type | Instructions |
| --------- | ---- | ---- |
| list | array | 会话列表 |
| total | int | 总数 |
| pageNo | int | 当前页码 |
| pageSize | int | 每页条数 |

### data.list[]

| Parameter | Type | Instructions |
| --------- | ---- | ---- |
| conversationId | string | 会话ID |
| ragId | string | 知识问答ID |
| title | string | 会话标题 |
| createdAt | string | 创建时间 |
| updatedAt | string | 更新时间 |

## 调用示例

```shell
curl -k --location 'http://localhost:8081/service/api/openapi/v1/rag/conversation/list?uuid=2004010127610351679&pageNo=1&pageSize=20' \
--header 'Authorization: Bearer <API Key>'
```

## 响应示例

```json
{
    "code": 0,
    "msg": "",
    "data": {
        "list": [
            {
                "conversationId": "56",
                "ragId": "2004010127610351679",
                "title": "产品保修政策咨询",
                "createdAt": "2026-08-13 10:15:00",
                "updatedAt": "2026-08-13 10:20:00"
            }
        ],
        "total": 1,
        "pageNo": 1,
        "pageSize": 20
    }
}
```
