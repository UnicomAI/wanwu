# 创建会话API

创建一条会话，返回的 `conversation_id` 用于[知识问答对话API](2.知识问答对话API.md)携带多轮上下文。

> 已发布问答的**必需前置步骤**：[知识问答对话API](2.知识问答对话API.md) 要求传 `conversation_id`，先用本接口创建。
> 同一个会话可反复问答，服务端自动携带该会话的上下文，历史也按会话归集。

## 请求接口

| Type | Instructions |
| ---- | ---- |
| 方法 | Http |
| 请求URL | 按照应用实际API根地址，例如：`http://localhost:8081/service/api/openapi/v1/rag/conversation` |
| 字符编码 | UTF-8 |
| 请求类型 | POST |
| 鉴权方式(header参数) | `Authorization: Bearer {API Key}` |
| 请求格式 | `Content-Type: application/json` |
| 响应格式 | `Content-Type: application/json` |

## 请求参数

| Parameter | Required | Type | Instructions |
| --------- | -------- | ---- | ---- |
| uuid | 是 | string | 知识问答UUID |
| title | 是 | string | 会话标题，一般取首个问题 |

## 响应参数

| Parameter | Type | Instructions |
| --------- | ---- | ---- |
| code | int | 状态码，0表示成功 |
| msg | string | 提示信息 |
| data | object | 响应数据 |

### data

| Parameter | Type | Instructions |
| --------- | ---- | ---- |
| conversation_id | string | 会话ID，用于问答与历史管理接口传参 |

## 调用示例

```shell
curl -k --location 'http://localhost:8081/service/api/openapi/v1/rag/conversation' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer <API Key>' \
--data '{
    "uuid": "2004010127610351679",
    "title": "产品保修政策咨询"
}'
```

## 响应示例

```json
{
    "code": 0,
    "msg": "",
    "data": {
        "conversation_id": "56"
    }
}
```
