# 草稿态会话历史API

获取草稿态问答的历史消息。草稿态每个知识问答只有**一条**会话，通过 `uuid` 定位，无需 `conversation_id`。

> 尚未发起过草稿态对话时返回空列表，不报错。

## 请求接口

| Type | Instructions |
| ---- | ---- |
| 方法 | Http |
| 请求URL | 按照应用实际API根地址，例如：`http://localhost:8081/service/api/openapi/v1/rag/conversation/draft/detail` |
| 字符编码 | UTF-8 |
| 请求类型 | GET |
| 鉴权方式(header参数) | `Authorization: Bearer {API Key}` |
| 响应格式 | `Content-Type: application/json` |

## 请求参数

| Parameter | Required | Type | Instructions |
| --------- | -------- | ---- | ---- |
| uuid | 是 | string | 知识问答UUID |
| pageNo | 是 | int | 页码，从 1 开始 |
| pageSize | 是 | int | 每页条数，从 1 开始 |

## 响应参数

与[会话历史消息API](5.会话历史消息API.md)一致。

## 调用示例

```shell
curl -k --location 'http://localhost:8081/service/api/openapi/v1/rag/conversation/draft/detail?uuid=2004010127610351679&pageNo=1&pageSize=20' \
--header 'Authorization: Bearer <API Key>'
```

## 响应示例

```json
{
    "code": 0,
    "msg": "",
    "data": {
        "list": [],
        "total": 0,
        "pageNo": 1,
        "pageSize": 20
    }
}
```
