# 草稿态对话API

基于**草稿配置**发起问答，不要求知识问答已发布，便于配置后先调试再发布。响应格式与[知识问答对话API](2.知识问答对话API.md)完全一致。

> **对话前必须先完成配置**，否则报错：
>
> - 对话大模型 `modelConfig`
> - 知识库 `knowledgeBaseConfig` 与问答库 `qaKnowledgeBaseConfig` **至少绑定一个**
> - 绑定了知识库时，知识库检索方式为混合检索（`matchType=mix`）且开启权重匹配（`priorityMatch=1`）时可不配 Rerank；除此之外的检索方式都需配置知识库 Rerank 模型 `rerankConfig`
> - 绑定了问答库时，需配置问答库 Rerank 模型 `qaRerankConfig`
>
> 草稿态每个知识问答只维护**一条**会话，由服务端按 `uuid` 自动复用或创建，历史照常落库。
> 因此本接口**不接受** `conversation_id`：草稿会话唯一，传了也无从选择，传已发布会话的 id 更会把草稿问答写进正式历史。

## 请求接口

| Type | Instructions |
| ---- | ---- |
| 方法 | Http |
| 请求URL | 按照应用实际API根地址，例如：`http://localhost:8081/service/api/openapi/v1/rag/chat/draft` |
| 字符编码 | UTF-8 |
| 请求类型 | POST |
| 鉴权方式(header参数) | `Authorization: Bearer {API Key}` |
| 请求格式 | `Content-Type: application/json` |
| 响应格式 | 非流式：`Content-Type: application/json`<br />流式：`Content-Type: text/event-stream` |

## 请求参数

| Parameter | Required | Type | Instructions |
| --------- | -------- | ---- | ---- |
| uuid | 是 | string | 知识问答UUID |
| query | 是 | string | 用户提出的问题或提示语 |
| stream | 否 | bool | 是否流式返回，默认 false |
| file_info | 否 | array | 随问题携带的文件，元素含 fileName、fileUrl、fileSize。**当前仅支持 1 张图片**（fileUrl 后缀 png/jpg/jpeg），且需打开视觉开关、对话模型支持图文问答、绑定多模态知识库、知识库 Rerank 为多模态 Rerank，详见[文件上传API](../4.文件管理/1.文件上传API.md) |

## 响应参数

与[知识问答对话API](2.知识问答对话API.md)一致。

## 调用示例

```shell
curl -k --location 'http://localhost:8081/service/api/openapi/v1/rag/chat/draft' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer <API Key>' \
--data '{
    "uuid": "2004010127610351679",
    "query": "保修期是多久？",
    "stream": false
}'
```

## 响应示例

```json
{
    "code": 0,
    "message": "success",
    "msg_id": "9f1c...",
    "data": {
        "output": "标准保修期为 12 个月。",
        "searchList": []
    },
    "history": [],
    "finish": 1
}
```
