# 知识问答对话API

基于**已发布**的知识问答发起提问。必须先用[创建会话API](1.创建会话API.md)拿到 `conversation_id`：服务端据此带上该会话的上下文，并把本轮问答落入该会话历史。参数与校验口径与平台页面侧的问答接口保持一致。

### 请求接口

| Type                 | Instructions                                                 |
| -------------------- | ------------------------------------------------------------ |
| 方法                 | Http                                                         |
| 请求URL              | 按照应用实际API根地址，例如：<br />`http://localhost:8081/service/api/openapi/v1/rag/chat` |
| 字符编码             | UTF-8                                                        |
| 请求类型             | POST                                                         |
| 鉴权方式(header参数) | `Authorization: Bearer {API Key}`                            |
| 请求格式             | `Content-Type: application/json`                             |
| 响应格式             | 非流式：`Content-Type: application/json`<br />流    式：`Content-Type: text/event-stream` |

### 请求参数

| Parameter | Required | Type   | Instructions                                                 |
| --------- | -------- | ------ | ------------------------------------------------------------ |
| uuid      | 是       | string | 文本问答唯一ID                                                |
| conversation_id | 是 | string | 会话ID，由[创建会话API](1.创建会话API.md)获取。已发布问答必须先建会话，口径与平台页面一致 |
| query     | 是       | string | 用户提出的问题或提示语                                       |
| stream    | 否       | bool   | 是否以流式接口的形式返回数据，默认为非流式。 true为流式，false为非流式。 |
| file_info | 否       | array  | 随问题携带的文件，元素含 fileName、fileUrl、fileSize。**当前仅支持 1 张图片**（fileUrl 后缀 png/jpg/jpeg），且需打开视觉开关、对话模型支持图文问答、绑定多模态知识库、知识库 Rerank 为多模态 Rerank，详见[文件上传API](../4.文件管理/1.文件上传API.md) |

### 响应参数

| Parameter | Type   | Instructions                                                 |
| --------- | ------ | ------------------------------------------------------------ |
| code      | int    | 状态码，用于表示请求成功或具体的错误类型                     |
| message   | string | 提示信息，通常用于提供关于code的详细解释或请求成功的确认信息 |
| msg_id    | string | 提示信息ID                                                   |
| data      | array  | 当前响应文本，包含了根据用户输入和知识库搜索得到的答案       |
| history   | array  | 包含之前对话历史的数组，用于上下文管理                       |
| finish    | int    | 仅在流式返回中有该字段。表示流是否结束，0：未结束，1：正常结束，2：生成长度导致结束，3：异常结束，4：命中安全护栏结束 |

#### data

| Parameter  | Type   | Instructions         |
| ---------- | ------ | -------------------- |
| output     | string | 当前响应文本内容片段 |
| searchList | array  | 知识增强搜索结果     |

#### searchList

| Parameter | Type   | Instructions |
| --------- | ------ | ------------ |
| kb_name   | string | 知识库名字   |
| snippet   | string | 知识内容片段 |
| title     | string | 文件标题     |
| meta_data | object | 知识片段元信息，原样透传知识库检索结果（流式与非流式返回一致），常见字段见下表 |

#### meta_data

| Parameter | Type   | Instructions |
| --------- | ------ | ------------ |
| file_name         | string | 文件名   |
| download_link     | string | 文件下载链接（带签名，有时效性） |
| page_num          | int array | 命中内容所在页码 |
| parent_title      | string array | 命中内容的上级标题 |
| row_num           | int    | 行号（表格类文档） |
| chunk_current_num | int    | 当前分片序号 |
| chunk_total_num   | int    | 文档总分片数 |
| bucket_name       | string | 存储桶名 |
| object_name       | string | 存储对象名 |
| doc_meta          | array  | 文档元数据（导入文档时设置的元数据） |

> meta_data 为透传字段，实际字段以检索结果为准，可能随版本增减，调用方请按可选字段处理。

#### history

| Parameter | Type   | Instructions |
| --------- | ------ | ------------ |
| query     | string | 请求文本     |
| response  | string | 模型响应文本 |

### 调用示例

#### 流式

```shell
curl -k --location 'http://localhost:8081/service/api/openapi/v1/rag/chat' \
--header 'Content-Type: application/json' \
--header 'Accept: application/json' \
--header 'Authorization: Bearer <API Key>' \
--data '{
    "uuid": "2001641058764591104",
    "query": "请一句话介绍DeepSeek",
    "stream": true
}'
```

#### 非流式

```shell
curl -k --location 'http://localhost:8081/service/api/openapi/v1/rag/chat' \
--header 'Content-Type: application/json' \
--header 'Accept: application/json' \
--header 'Authorization: Bearer <API Key>' \
--data '{
    "uuid": "2001641058764591104",
    "query": "请一句话介绍DeepSeek",
    "stream": false
}'
```
