# 会话历史消息API

获取指定会话的历史问答明细，分页返回，含检索命中列表、深度思考内容与各阶段耗时。

## 请求接口

| Type | Instructions |
| ---- | ---- |
| 方法 | Http |
| 请求URL | 按照应用实际API根地址，例如：`http://localhost:8081/service/api/openapi/v1/rag/conversation/detail` |
| 字符编码 | UTF-8 |
| 请求类型 | GET |
| 鉴权方式(header参数) | `Authorization: Bearer {API Key}` |
| 响应格式 | `Content-Type: application/json` |

## 请求参数

| Parameter | Required | Type | Instructions |
| --------- | -------- | ---- | ---- |
| uuid | 是 | string | 知识问答UUID |
| conversation_id | 是 | string | 会话ID（由创建会话接口返回） |
| pageNo | 是 | int | 页码，从 1 开始 |
| pageSize | 是 | int | 每页条数，从 1 开始 |

## 响应参数

| Parameter | Type | Instructions |
| --------- | ---- | ---- |
| code | int | 状态码，0表示成功 |
| msg | string | 提示信息 |
| data | object | 响应数据，含 list / total / pageNo / pageSize |

### data.list[]

| Parameter | Type | Instructions |
| --------- | ---- | ---- |
| detailId | string | 问答明细ID，按条删除时使用 |
| ragId | string | 知识问答ID |
| conversationId | string | 会话ID |
| prompt | string | 用户提问 |
| response | string | 模型回答 |
| reasoningContent | string | 深度思考过程；`null` 表示该轮没有思考，`""` 表示思考过但无内容 |
| searchList | string | 知识库引用段落（JSON 字符串）；`null` 表示未走知识库检索，`""` 表示检索无召回 |
| qaSearchList | string | 问答库命中结果（JSON 字符串），与 searchList 互斥 |
| errMessage | string | 本轮错误信息，正常为空 |
| qaErrMessage | string | 问答库检索失败原因，非空表示本轮由问答库报错后转知识库 |
| requestFiles | array | 提问时携带的文件 |
| createdAt | int | 创建时间（毫秒时间戳） |
| reasoningTimeCost | object | 深度思考起止（毫秒），start/end 均为 0 表示未发生 |
| searchListTimeCost | object | 知识库检索起止（毫秒） |
| qaSearchListTimeCost | object | 问答库检索起止（毫秒） |

## 调用示例

```shell
curl -k --location 'http://localhost:8081/service/api/openapi/v1/rag/conversation/detail?uuid=2004010127610351679&conversation_id=56&pageNo=1&pageSize=20' \
--header 'Authorization: Bearer <API Key>'
```
