# 文件上传API

上传随问题携带的文件，返回的 `fileUrl` 填进[知识问答对话API](../3.会话管理/2.知识问答对话API.md)或[草稿态对话API](../3.会话管理/3.草稿态对话API.md)的 `file_info`，即可针对该文件提问。

> 问答接口的 `file_info.fileUrl` 必须是平台可访问的地址，因此需先经本接口上传取得。

## 使用前提（重要）

带文件提问目前只支持**图片**，需同时满足以下条件：

- **文件类型**：`fileUrl` 必须以 `.png`/`.jpg`/`.jpeg` 结尾，且不能带查询参数。其他类型（pdf、docx、xlsx 等）算法侧无法识别，接口会报错。若要让模型读文档内容，请把文档导入知识库，而不是走本接口。
- **视觉开关**：应用配置里的「视觉」开关必须打开（`visionConfig.picNum` 大于 0）。
- **对话模型**：应用绑定的对话模型必须支持图文问答（模型标签「图文问答」），否则报错。
- **知识库**：应用至少绑定一个多模态知识库（多模态知识库建库时已强制使用多模态 embedding 模型）。
- **Rerank 模型**：知识库 Rerank 模型必须是多模态 Rerank（`multimodal-rerank`）。
- **数量**：`file_info` 当前只支持 1 个文件，超过报错。

## 请求接口

| Type | Instructions |
| ---- | ---- |
| 方法 | Http |
| 请求URL | 按照应用实际API根地址，例如：`http://localhost:8081/service/api/openapi/v1/rag/file/upload` |
| 字符编码 | UTF-8 |
| 请求类型 | POST |
| 鉴权方式(header参数) | `Authorization: Bearer {API Key}` |
| 请求格式 | `Content-Type: multipart/form-data` |
| 响应格式 | `Content-Type: application/json` |

## 请求参数

| Parameter | Required | Type | Instructions |
| --------- | -------- | ---- | ---- |
| files | 是 | file | 文件，重复该字段可一次上传多个。带文件提问只支持 png/jpg/jpeg |

## 响应参数

| Parameter | Type | Instructions |
| --------- | ---- | ---- |
| code | int | 状态码，0表示成功 |
| msg | string | 提示信息 |
| data | object | 响应数据 |

### data.fileList[]

| Parameter | Type | Instructions |
| --------- | ---- | ---- |
| fileIndex | int | 文件序号，与上传顺序对应 |
| fileUrl | string | 文件地址，填入问答接口的 `file_info[].fileUrl` |

## 调用示例

```shell
curl -k --location 'http://localhost:8081/service/api/openapi/v1/rag/file/upload' \
--header 'Authorization: Bearer <API Key>' \
--form 'files=@"/path/to/设备铭牌.png"'
```

## 响应示例

```json
{
    "code": 0,
    "msg": "",
    "data": {
        "fileList": [
            {
                "fileIndex": 0,
                "fileUrl": "https://.../设备铭牌.png"
            }
        ]
    }
}
```

## 配合问答使用

```shell
curl -k --location 'http://localhost:8081/service/api/openapi/v1/rag/chat' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer <API Key>' \
--data '{
    "uuid": "2004010127610351679",
    "conversation_id": "56",
    "query": "这张铭牌上的型号和出厂日期是什么？",
    "file_info": [
        { "fileName": "设备铭牌.png", "fileUrl": "https://.../设备铭牌.png", "fileSize": 20480 }
    ]
}'
```
