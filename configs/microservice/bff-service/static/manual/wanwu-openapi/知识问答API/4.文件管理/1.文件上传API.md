# 文件上传API

带文件提问的文件用[上传文件API](../../知识库API/2.文档管理/1.上传文件API.md)（`POST /v1/file/upload/direct`）上传，把返回的 `filePath` 填进[知识问答对话API](../3.会话管理/2.知识问答对话API.md)或[草稿态对话API](../3.会话管理/3.草稿态对话API.md)的 `file_info[].fileUrl`，即可针对该文件提问。

> 问答接口的 `file_info.fileUrl` 必须是平台可访问的地址，因此需先上传取得，不能直接填外部链接。

## 使用前提（重要）

带文件提问目前只支持**图片**，需同时满足以下条件：

- **文件类型**：png/jpg/jpeg。其他类型（pdf、docx、xlsx 等）算法侧无法识别。若要让模型读文档内容，请把文档导入知识库。
- **视觉开关**：应用配置里的「视觉」开关必须打开（`visionConfig.picNum` 大于 0）。
- **对话模型**：应用绑定的对话模型必须支持图文问答（模型标签「图文问答」），否则报错。
- **知识库**：应用至少绑定一个多模态知识库（多模态知识库建库时已强制使用多模态 embedding 模型）。
- **Rerank 模型**：知识库 Rerank 模型必须是多模态 Rerank（`multimodal-rerank`）。
- **数量**：`file_info` 当前只支持 1 个文件，超过报错。

## 上传

参数与响应见[上传文件API](../../知识库API/2.文档管理/1.上传文件API.md)，此处只取响应里的 `filePath`。

```shell
curl -k --location 'http://localhost:8081/service/api/openapi/v1/file/upload/direct' \
--header 'Authorization: Bearer <API Key>' \
--form 'files=@"/path/to/设备铭牌.png"'
```

```json
{
    "code": 0,
    "msg": "",
    "data": {
        "files": [
            {
                "fileName": "设备铭牌.png",
                "fileId": "7ef84358-1137-4eb6-8ae0-f3e1cc6e584d.png",
                "filePath": "http://minio-wanwu:9000/file-upload/file-expire/7ef84358-1137-4eb6-8ae0-f3e1cc6e584d.png",
                "fileSize": 20480
            }
        ]
    }
}
```

## 配合问答使用

`file_info[].fileUrl` 填上一步的 `filePath`。

```shell
curl -k --location 'http://localhost:8081/service/api/openapi/v1/rag/chat' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer <API Key>' \
--data '{
    "uuid": "2004010127610351679",
    "conversation_id": "56",
    "query": "这张铭牌上的型号和出厂日期是什么？",
    "file_info": [
        {
            "fileName": "设备铭牌.png",
            "fileUrl": "http://minio-wanwu:9000/file-upload/file-expire/7ef84358-1137-4eb6-8ae0-f3e1cc6e584d.png",
            "fileSize": 20480
        }
    ]
}'
```
