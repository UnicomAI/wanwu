# 发布知识问答API

发布知识问答，发布后可通过[知识问答对话API](../3.会话管理/2.知识问答对话API.md)进行正式问答。

> **发布前必须先完成配置**，否则发布报错：
>
> - 对话大模型 `modelConfig`
> - 知识库 `knowledgeBaseConfig` 与问答库 `qaKnowledgeBaseConfig` **至少绑定一个**
> - 绑定了知识库时，知识库检索方式为混合检索（`matchType=mix`）且开启权重匹配（`priorityMatch=1`）时可不配 Rerank；除此之外的检索方式都需配置知识库 Rerank 模型 `rerankConfig`
> - 绑定了问答库时，需配置问答库 Rerank 模型 `qaRerankConfig`

## 请求接口

| Type | Instructions |
| ---- | ---- |
| 方法 | Http |
| 请求URL | 按照应用实际API根地址，例如：`http://localhost:8081/service/api/openapi/v1/rag/publish` |
| 字符编码 | UTF-8 |
| 请求类型 | POST |
| 鉴权方式(header参数) | `Authorization: Bearer {API Key}` |
| 请求格式 | `Content-Type: application/json` |
| 响应格式 | `Content-Type: application/json` |

## 请求参数

| Parameter | Required | Type | Instructions |
| --------- | -------- | ---- | ---- |
| uuid | 是 | string | 知识问答UUID |
| version | 是 | string | 版本号，格式 `vX.Y.Z`，如 `v1.0.0` |
| desc | 是 | string | 版本描述 |
| publishType | 是 | string | 发布范围：`public` 系统公开、`organization` 组织公开、`private` 私密 |

## 响应参数

| Parameter | Type | Instructions |
| --------- | ---- | ---- |
| code | int | 状态码，0表示成功 |
| msg | string | 提示信息 |
| data | object | 空 |

## 调用示例

```shell
curl -k --location 'http://localhost:8081/service/api/openapi/v1/rag/publish' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer <API Key>' \
--data '{
    "uuid": "2004010127610351679",
    "version": "v1.0.0",
    "desc": "首次发布",
    "publishType": "private"
}'
```

## 响应示例

```json
{
    "code": 0,
    "msg": "",
    "data": null
}
```
