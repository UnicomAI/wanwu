# 知识问答详情API

获取知识问答的完整配置，通过 `published` 参数控制返回草稿态还是已发布态。

> 返回的模型 `modelId` 均为**模型UUID**，可直接用于[配置更新API](2.配置更新API.md)。

## 请求接口

| Type | Instructions |
| ---- | ---- |
| 方法 | Http |
| 请求URL | 按照应用实际API根地址，例如：`http://localhost:8081/service/api/openapi/v1/rag/info` |
| 字符编码 | UTF-8 |
| 请求类型 | GET |
| 鉴权方式(header参数) | `Authorization: Bearer {API Key}` |
| 响应格式 | `Content-Type: application/json` |

## 请求参数

| Parameter | Required | Type | Instructions |
| --------- | -------- | ---- | ---- |
| uuid | 是 | string | 知识问答UUID |
| published | 否 | bool | `true` 返回已发布态配置，`false`（默认）返回草稿态 |

## 响应参数

| Parameter | Type | Instructions |
| --------- | ---- | ---- |
| code | int | 状态码，0表示成功 |
| msg | string | 提示信息 |
| data | object | 知识问答详情 |

### data

| Parameter | Type | Instructions |
| --------- | ---- | ---- |
| ragId | string | 知识问答ID，等同于 uuid |
| name | string | 名称 |
| desc | string | 描述 |
| modelConfig | object | 对话模型配置 |
| rerankConfig | object | 知识库 Rerank 模型配置 |
| qaRerankConfig | object | 问答库 Rerank 模型配置 |
| knowledgeBaseConfig | object | 知识库配置 |
| qaKnowledgeBaseConfig | object | 问答库配置 |
| safetyConfig | object | 安全护栏配置 |
| visionConfig | object | 视觉开关配置 |
| recommendQuestion | array | 推荐问题 |
| createdAt | string | 创建时间 |
| updatedAt | string | 更新时间 |

## 调用示例

```shell
curl -k --location 'http://localhost:8081/service/api/openapi/v1/rag/info?uuid=2004010127610351679' \
--header 'Authorization: Bearer <API Key>'
```
