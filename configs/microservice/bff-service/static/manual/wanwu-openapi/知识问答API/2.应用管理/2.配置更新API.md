# 配置更新API

更新知识问答的模型、知识库、问答库、安全护栏等配置。

> **只传要改的字段**：除 `uuid` 外所有字段均为可选，未传的字段沿用当前草稿配置，不会被清空。
>
> **模型 id 传模型UUID**：`modelConfig`、`rerankConfig`、`qaRerankConfig` 中的 `modelId` 传模型列表API返回的模型UUID。

## 请求接口

| Type | Instructions |
| ---- | ---- |
| 方法 | Http |
| 请求URL | 按照应用实际API根地址，例如：`http://localhost:8081/service/api/openapi/v1/rag/config` |
| 字符编码 | UTF-8 |
| 请求类型 | PUT |
| 鉴权方式(header参数) | `Authorization: Bearer {API Key}` |
| 请求格式 | `Content-Type: application/json` |
| 响应格式 | `Content-Type: application/json` |

## 请求参数

| Parameter | Required | Type | Instructions |
| --------- | -------- | ---- | ---- |
| uuid | 是 | string | 知识问答UUID |
| modelConfig | 否 | object | 对话大模型配置，**问答与发布前必须配置** |
| rerankConfig | 否 | object | 知识库 Rerank 模型配置。绑定知识库后，混合检索+权重匹配时可不配，其余检索方式都必须配置 |
| qaRerankConfig | 否 | object | 问答库 Rerank 模型配置，绑定问答库后必须配置 |
| knowledgeBaseConfig | 否 | object | 知识库配置，与 qaKnowledgeBaseConfig **至少配置一个**才能问答与发布 |
| qaKnowledgeBaseConfig | 否 | object | 问答库配置，与 knowledgeBaseConfig **至少配置一个**才能问答与发布 |
| safetyConfig | 否 | object | 安全护栏配置 |
| visionConfig | 否 | object | 视觉开关配置 |
| recommendQuestion | 否 | array | 推荐问题列表 |

### modelConfig / rerankConfig / qaRerankConfig

| Parameter | Required | Type | Instructions |
| --------- | -------- | ---- | ---- |
| modelId | 是 | string | 模型UUID |
| model | 否 | string | 模型名称 |
| modelType | 否 | string | 模型类型，如 `llm`、`rerank` |
| config | 否 | object | 模型参数，如 temperature、maxTokens 等 |

### knowledgeBaseConfig

| Parameter | Required | Type | Instructions |
| --------- | -------- | ---- | ---- |
| knowledgebases | 是 | array | 关联知识库列表，元素含知识库 id |
| config | 是 | object | 检索参数：matchType（匹配方式）、topK、threshold（阈值）、priorityMatch（优先匹配） |

## 响应参数

| Parameter | Type | Instructions |
| --------- | ---- | ---- |
| code | int | 状态码，0表示成功 |
| msg | string | 提示信息 |
| data | object | 空 |

## 调用示例

```shell
curl -k --location --request PUT 'http://localhost:8081/service/api/openapi/v1/rag/config' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer <API Key>' \
--data '{
    "uuid": "2004010127610351679",
    "modelConfig": {
        "modelId": "1810783070475849728",
        "model": "DeepSeek-V3",
        "modelType": "llm"
    },
    "knowledgeBaseConfig": {
        "knowledgebases": [
            { "id": "1809876543210987654" }
        ],
        "config": {
            "matchType": "mix",
            "topK": 5,
            "threshold": 0.4,
            "priorityMatch": 1
        }
    }
}'
```

## 响应示例

```json
{
    "code": 0,
    "msg": "",
    "data": null
}
```
