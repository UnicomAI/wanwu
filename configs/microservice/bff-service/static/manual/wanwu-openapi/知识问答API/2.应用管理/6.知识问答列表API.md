# 知识问答列表API

获取当前 API Key 所属用户下的全部知识问答（含草稿态与已发布态），可按名称模糊筛选。

## 请求接口

| Type | Instructions |
| ---- | ---- |
| 方法 | Http |
| 请求URL | 按照应用实际API根地址，例如：`http://localhost:8081/service/api/openapi/v1/rag/list` |
| 字符编码 | UTF-8 |
| 请求类型 | GET |
| 鉴权方式(header参数) | `Authorization: Bearer {API Key}` |
| 响应格式 | `Content-Type: application/json` |

## 请求参数

| Parameter | Required | Type | Instructions |
| --------- | -------- | ---- | ---- |
| name | 否 | string | 按名称模糊筛选 |

## 响应参数

| Parameter | Type | Instructions |
| --------- | ---- | ---- |
| code | int | 状态码，0表示成功 |
| msg | string | 提示信息 |
| data | object | 响应数据 |

### data.list[]

| Parameter | Type | Instructions |
| --------- | ---- | ---- |
| uuid | string | 知识问答UUID，后续接口传参主键 |
| name | string | 名称 |
| desc | string | 描述 |
| avatar | object | 图标信息 |
| publishType | string | 发布范围，空字符串表示未发布（草稿） |
| version | string | 已发布版本号，未发布时为空 |
| createdAt | string | 创建时间 |
| updatedAt | string | 最后更新时间 |

## 调用示例

```shell
curl -k --location 'http://localhost:8081/service/api/openapi/v1/rag/list?name=产品' \
--header 'Authorization: Bearer <API Key>'
```

## 响应示例

```json
{
    "code": 0,
    "msg": "",
    "data": {
        "list": [
            {
                "uuid": "2004010127610351679",
                "name": "产品知识问答",
                "desc": "基于产品手册的问答应用",
                "publishType": "private",
                "version": "v1.0.0",
                "createdAt": "2026-08-13 10:15:00",
                "updatedAt": "2026-08-13 11:20:00"
            }
        ]
    }
}
```
