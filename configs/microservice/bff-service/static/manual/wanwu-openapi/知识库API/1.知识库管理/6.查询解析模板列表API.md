# 查询解析模板列表API
查询当前 API Key 所属用户的解析模板列表。解析模板把「分段方式 + 解析方式」按文档类型存成可复用的配置，[文档导入API](../2.文档管理/2.文档导入API.md)、[新建知识库API](1.新建知识库API.md)、[编辑知识库API](2.编辑知识库API.md) 里用到的 `templateId` 都从本接口获取。

每种文档类型都有一个内置（默认）模板，由平台自动创建，`builtIn` 为 `true`，不可修改；其余为用户自建模板。视频/音频/图片没有内置模板，必须自建后才能使用。

## 接口信息

| 项目 | 说明 |
|------|------|
| **请求方法** | GET |
| **请求URL** | `http://localhost:8081/service/api/openapi/v1/knowledge/parseTemplate` |
| **字符编码** | UTF-8 |
| **响应格式** | `Content-Type: application/json` |
| 鉴权方式(header参数) | `Authorization: Bearer {API Key}`                        |


## 请求参数（Query）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `docType` | String | 否 | 按文档类型过滤：pdf/word/ppt/excel/csv/txt/html/markdown/wps/ofd/video/audio/image；不传返回全部类型 |


## 响应参数

| 状态码 | 说明 | 响应体结构 |
|--------|------|------------|
| 200 | 请求成功 | `{"code": 0, "data": ParseTemplateListResp, "msg": ""}` |


### ParseTemplateListResp 对象
| 字段名 | 类型 | 说明 |
|--------|------|------|
| `list` | Array[[ParseTemplateInfo](#parsetemplateinfo-对象)] | 解析模板列表，按创建时间倒序 |

### ParseTemplateInfo 对象
| 字段名 | 类型 | 说明 |
|--------|------|------|
| `templateId` | String | 解析模板id，用于绑定到知识库或导入文档时指定 |
| `name` | String | 模板名称；内置（默认）模板固定为「内置（默认）」 |
| `docType` | String | 该模板适用的文档类型 |
| `builtIn` | Boolean | 是否内置（默认）模板：`true` 平台自动创建、不可修改；`false` 用户自建 |
| `docSegment` | [DocSegment](#docsegment-对象) | 分段配置 |
| `docAnalyzer` | Array[String] | 文档解析类型：text 文字提取 / model OCR解析 / asr 音频解析 / multimodal 图文问答解析 |
| `parserModelId` | String | OCR解析模型id，`docAnalyzer` 含 `model` 时有值 |
| `asrModelId` | String | ASR模型id，`docAnalyzer` 含 `asr` 时有值 |
| `multimodalModelId` | String | 图文问答模型id，`docAnalyzer` 含 `multimodal` 时有值 |
| `docPreprocess` | Array[String] | 文本预处理规则：replaceSymbols 替换连续空格换行制表符 / deleteLinks 删除URL和邮箱 |
| `createdAt` | String | 创建时间，格式 YYYY-MM-DD HH:mm:ss |
| `updatedAt` | String | 更新时间，格式 YYYY-MM-DD HH:mm:ss |

### DocSegment 对象
| 字段名 | 类型 | 说明 |
|--------|------|------|
| `segmentMethod` | String | 分段方法：`0` 通用分段 / `1` 父子分段 |
| `segmentType` | String | 分段方式：`0` 自动分段 / `1` 自定义分段 |
| `splitter` | Array[String] | 分段标识，自定义分段时有值 |
| `maxSplitter` | Integer | 可分割最大值 |
| `overlap` | Number | 可重叠值，0~1 |
| `subSplitter` | Array[String] | 子块分段标识，父子分段时有值 |
| `subMaxSplitter` | Integer | 子块可分割最大值，不大于 `maxSplitter` |


## 请求示例

```shell
curl --location 'http://localhost:8081/service/api/openapi/v1/knowledge/parseTemplate?docType=pdf' \
--header 'Authorization: Bearer {API Key}'
```
