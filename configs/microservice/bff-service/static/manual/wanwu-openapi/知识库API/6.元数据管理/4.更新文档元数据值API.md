# 更新文档元数据值API

批量设置、修改、删除文档的元数据值，一次请求作用于`docIdList`中的全部文档。key需先通过「定义知识库元数据key」在知识库上定义。只改一个文档时，`docIdList`传单个元素即可。

文档需处于处理完成状态，否则无法修改元数据。

## 请求接口

| Type     | Instructions                                                 |
| -------- | ------------------------------------------------------------ |
| 方法     | Http                                                         |
| 请求URL  | 按照应用实际API根地址，例如：<br />`http://localhost:8081/service/api/openapi/v1/knowledge/doc/meta/update` |
| 调用方式 | 同步调用                                                      |
| 字符编码 | UTF-8                                                        |
| 请求类型 | POST                                                         |
| 鉴权方式 | `Authorization: Bearer {API Key}` |
| 请求格式 | `Content-Type: application/json`                             |
| 响应格式 | `Content-Type: application/json`                             |

## 请求参数

| Parameter    | Required  | Type   | Instructions                                                 |
|---------------|----| ------ |--------------------------------------------------------------|
| knowledgeId | 是  | string | 知识库Id                      |
| docIdList | 是  | string array | 文档id列表，需全部属于该知识库                      |
| metaValueList | 是  | object array | 元数据值操作列表，最多100条，同一key只能出现一次                      |

### metaValueList中详细字段

| Parameter    | Required  | Type   | Instructions                                                 |
|---------------|----| ------ |--------------------------------------------------------------|
| option | 是  | string | 操作类型：add(文档无该key则新增，已有则覆盖)、update(仅在文档已有该key时更新)、delete(删除该key的值)                      |
| metaKey | 是  | string | 元数据key，需已在知识库元数据中定义                      |
| metaValue | 否  | string | 元数据值，option为delete时可不填；metaValueType为number/time时传数字字符串（time为毫秒时间戳）                      |
| metaValueType | 否  | string | 值类型，option为add/update时必填，需与key的定义一致：string/number/time                      |

## 响应参数

| Parameter          | Type         | Instructions   |
|--------------------| ------------ |--------------|
| code               | int          | 状态码        |
| data               | object       | 返回数据，固定为null   |
| msg                | string       | 返回信息       |

## 请求示例

```shell
curl --location 'http://localhost:8081/service/api/openapi/v1/knowledge/doc/meta/update' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {API Key}' \
--data '{
    "knowledgeId": "2072931915169533952",
    "docIdList": [
        "2072931978688073728"
    ],
    "metaValueList": [
        {
            "option": "add",
            "metaKey": "author",
            "metaValue": "张三",
            "metaValueType": "string"
        }
    ]
}'
```

## 响应示例

```json
{
  "code": 0,
  "data": null,
  "msg": ""
}
```

## 常见错误码

| Code   | Instructions                                                 |
|--------|--------------------------------------------------------------|
| 110001 | 参数错误，如key格式非法、同一key重复、option取值非法、metaValueList超过100条 |
| 142016 | 该文档不存在（如docIdList中的文档不属于该知识库） |
| 142009 | 非处理完成文档无法更新元数据，请稍后重试 |
| 145016 | 更新知识库元数据失败，请稍后重试 |
