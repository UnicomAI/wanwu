# 获取知识库元数据key列表API

获取指定知识库已定义的元数据key列表。元数据的使用分两步：先在知识库上定义key（见「定义知识库元数据key」），再给文档设置对应的值（见「更新文档元数据值」）。

## 请求接口

| Type     | Instructions                                                 |
| -------- | ------------------------------------------------------------ |
| 方法     | Http                                                         |
| 请求URL  | 按照应用实际API根地址，例如：<br />`http://localhost:8081/service/api/openapi/v1/knowledge/meta/list` |
| 调用方式 | 同步调用                                                      |
| 字符编码 | UTF-8                                                        |
| 请求类型 | GET                                                          |
| 鉴权方式 | `Authorization: Bearer {API Key}` |
| 请求格式 | `Content-Type: application/json`                             |
| 响应格式 | `Content-Type: application/json`                             |

## 请求参数

| Parameter    | Required  | Type   | Instructions                                                 |
|---------------|----| ------ |--------------------------------------------------------------|
| knowledgeId | 是  | string | 知识库Id                      |

## 响应参数

| Parameter          | Type         | Instructions   |
|--------------------| ------------ |--------------|
| code               | int          | 状态码        |
| data               | object       | 返回数据   |
| msg                | string       | 返回信息       |

### data中详细字段

| Parameter             | Type         | Instructions   |
|--------------------   |--------------| ---------- |
| knowledgeMetaList     | object array | 元数据key列表，无定义时为null   |

### knowledgeMetaList中详细字段

| Parameter             | Type         | Instructions   |
|--------------------   |--------------| ---------- |
| metaId                | string       | 元数据id，修改/删除key时需要传入   |
| metaKey               | string       | 元数据key   |
| metaValueType         | string       | 值类型：string/number/time   |
| metaValue             | string       | 该字段在key定义上恒为空，文档的元数据值请调用「获取文档元数据值列表」   |

## 请求示例

```shell
curl --location 'http://localhost:8081/service/api/openapi/v1/knowledge/meta/list?knowledgeId=2072931915169533952' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {API Key}'
```

## 响应示例

```json
{
  "code": 0,
  "data": {
    "knowledgeMetaList": [
      {
        "metaId": "2081672966067720192",
        "metaKey": "author",
        "metaValueType": "string",
        "metaValue": ""
      }
    ]
  },
  "msg": ""
}
```
