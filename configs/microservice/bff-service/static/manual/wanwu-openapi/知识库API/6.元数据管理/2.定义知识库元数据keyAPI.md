# 定义知识库元数据keyAPI

在知识库上新增、修改、删除元数据key定义。一次请求可提交多个操作，同一key在一次请求中只能出现一次。key定义好之后，再调用「更新文档元数据值」给文档设置值。

## 请求接口

| Type     | Instructions                                                 |
| -------- | ------------------------------------------------------------ |
| 方法     | Http                                                         |
| 请求URL  | 按照应用实际API根地址，例如：<br />`http://localhost:8081/service/api/openapi/v1/knowledge/meta/update` |
| 调用方式 | 同步调用                                                      |
| 字符编码 | UTF-8                                                        |
| 请求类型 | POST                                                         |
| 鉴权方式 | `Authorization: Bearer {API Key}` |
| 请求格式 | `Content-Type: application/json`                             |
| 响应格式 | `Content-Type: application/json`                             |

## 请求参数

| Parameter    | Required  | Type   | Instructions                                                 |
|---------------|----| ------ |--------------------------------------------------------------|
| knowledgeId | 是  | string | 知识库Id                      |
| metaKeyList | 是  | object array | 元数据key操作列表，最多100条                      |

### metaKeyList中详细字段

| Parameter    | Required  | Type   | Instructions                                                 |
|---------------|----| ------ |--------------------------------------------------------------|
| option | 是  | string | 操作类型：add(新增)、update(修改)、delete(删除)                      |
| metaId | 否  | string | 元数据id，option为update/delete时必填，可由「获取知识库元数据key列表」获得                      |
| metaKey | 否  | string | 元数据key，option为add/update时必填；只能包含小写字母、数字和下划线，且以小写字母开头                      |
| metaValueType | 否  | string | 值类型，option为add/update时必填：string/number/time                      |

## 响应参数

| Parameter          | Type         | Instructions   |
|--------------------| ------------ |--------------|
| code               | int          | 状态码        |
| data               | object       | 返回数据，固定为null   |
| msg                | string       | 返回信息       |

## 请求示例

```shell
curl --location 'http://localhost:8081/service/api/openapi/v1/knowledge/meta/update' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {API Key}' \
--data '{
    "knowledgeId": "2072931915169533952",
    "metaKeyList": [
        {
            "option": "add",
            "metaKey": "author",
            "metaValueType": "string"
        },
        {
            "option": "update",
            "metaId": "2081672966067720192",
            "metaKey": "writer",
            "metaValueType": "string"
        },
        {
            "option": "delete",
            "metaId": "2081672966067720193"
        }
    ]
}'
```

## 响应示例

```json
{
  "code": 0,
  "data": null,
  "msg": ""
}
```

## 常见错误码

| Code   | Instructions                                                 |
|--------|--------------------------------------------------------------|
| 110001 | 参数错误，如key格式非法、同一key重复、option取值非法、metaKeyList超过100条 |
| 145018 | 已存在同名元数据key |
| 145015 | 新增知识库元数据失败，请稍后重试 |
| 145016 | 更新知识库元数据失败，请稍后重试 |
| 145017 | 删除知识库元数据失败，请稍后重试 |
| 145021 | 部分元数据更新成功（一次请求内多个操作部分失败） |
