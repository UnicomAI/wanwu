# 获取文档元数据值列表API

按文档id列表查询这批文档上已设置的元数据值。结果按元数据key聚合：`metaValue`是该key在所选文档中出现过的值集合（已去重），不区分具体属于哪个文档；值为空的元数据不返回。

若需要按单个文档查看元数据值，请调用「获取文档分片列表」，其响应中的`metaDataList`即为该文档的元数据值。

## 请求接口

| Type     | Instructions                                                 |
| -------- | ------------------------------------------------------------ |
| 方法     | Http                                                         |
| 请求URL  | 按照应用实际API根地址，例如：<br />`http://localhost:8081/service/api/openapi/v1/knowledge/doc/meta/list` |
| 调用方式 | 同步调用                                                      |
| 字符编码 | UTF-8                                                        |
| 请求类型 | POST                                                         |
| 鉴权方式 | `Authorization: Bearer {API Key}` |
| 请求格式 | `Content-Type: application/json`                             |
| 响应格式 | `Content-Type: application/json`                             |

## 请求参数

| Parameter    | Required  | Type   | Instructions                                                 |
|---------------|----| ------ |--------------------------------------------------------------|
| knowledgeId | 是  | string | 知识库Id                      |
| docIdList | 是  | string array | 文档id列表，需全部属于该知识库                      |

## 响应参数

| Parameter          | Type         | Instructions   |
|--------------------| ------------ |--------------|
| code               | int          | 状态码        |
| data               | object       | 返回数据   |
| msg                | string       | 返回信息       |

### data中详细字段

| Parameter             | Type         | Instructions   |
|--------------------   |--------------| ---------- |
| knowledgeMetaValues   | object array | 元数据值列表，无数据时为空数组   |

### knowledgeMetaValues中详细字段

| Parameter             | Type         | Instructions   |
|--------------------   |--------------| ---------- |
| metaId                | string       | 元数据id   |
| metaKey               | string       | 元数据key   |
| metaValue             | string array | 该key在所选文档中出现过的值（已去重）   |
| metaValueType         | string       | 值类型：string/number/time   |

## 请求示例

```shell
curl --location 'http://localhost:8081/service/api/openapi/v1/knowledge/doc/meta/list' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {API Key}' \
--data '{
    "knowledgeId": "2072931915169533952",
    "docIdList": [
        "2072931978688073728"
    ]
}'
```

## 响应示例

```json
{
  "code": 0,
  "data": {
    "knowledgeMetaValues": [
      {
        "metaId": "2081673054894690304",
        "metaKey": "author",
        "metaValue": [
          "张三"
        ],
        "metaValueType": "string"
      }
    ]
  },
  "msg": ""
}
```

## 常见错误码

| Code   | Instructions                                                 |
|--------|--------------------------------------------------------------|
| 142016 | 该文档不存在（如docIdList中的文档不属于该知识库） |
| 145014 | 查询知识库元数据失败，请稍后重试 |
