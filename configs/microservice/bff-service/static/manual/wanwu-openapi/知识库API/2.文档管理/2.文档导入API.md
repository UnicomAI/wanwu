# 文档导入API

文档导入API 用于把已上传的文件正式导入知识库：提交后，后台会按您指定的分段方式和解析方式对文档进行切分、解析和向量化，解析完成后文档即可被知识库检索命中。

## 使用流程

1. **上传文件**：先调用[上传文件API](1.上传文件API.md)把文件上传到平台，拿到返回的 `fileId`；
2. **导入文档（本接口）**：以 `fileId` 作为 `docId`，携带分段配置（`docSegment`）和解析方式（`docAnalyzer`）调用本接口；
3. **查询进度**：本接口为异步接口，提交成功仅代表任务创建成功，解析进度和结果请通过[获取文档列表API](4.获取文档列表API.md)、[获取文档导入状态API](3.获取文档导入状态API.md)查询。

支持以下两种上传方式：

| 上传方式 | docImportType | 适用知识库 | 支持的文件 |
|--------------|-----|-----------|----------------------------------|
| 文本/表格文件上传 | 0 | 文本知识库 | pdf/docx/doc/pptx/wps/ofd/xlsx/xls/csv/txt/html/md 及 zip/tar.gz 压缩包 |
| 多模态文件上传 | 0 | 多模态知识库 | 除上述文档外，还支持图片/音频/视频 |

## 分段方式与解析方式

以下配置对应页面"新增文件-参数设置"步骤中的各项。

**分段方式**（`docSegment`，控制文档如何切分成片段）：

- **通用分段**（`segmentMethod="0"`）：检索和召回的分段内容相同；
- **父子分段**（`segmentMethod="1"`）：父分段用作上下文、子分段用于检索。

共有三种配置组合，各自需要的字段如下（页面名词与参数的对应见括号）：

| 页面配置 | 参数取值 | 需要的分段字段 |
|---------|---------|-----------|
| 通用分段 + 自动分段 | `segmentMethod="0"` + `segmentType="0"` | 无需其他字段，系统按默认方式切分 |
| 通用分段 + 自定义分段 | `segmentMethod="0"` + `segmentType="1"` | `splitter`（分段标识，如 `["\n\n"]`）、`maxSplitter`（可分割最大值，如 1024）、`overlap`（可重叠值，0~1，如 0.2） |
| 父子分段 | `segmentMethod="1"` | 父块：`splitter` + `maxSplitter`；子块：`subSplitter`（如 `["\n"]`） + `subMaxSplitter`（如 200，**不能大于父块的 maxSplitter**） |

**文本预处理规则**（`docPreprocess`，可选，配合自定义分段/父子分段使用）：

- `replaceSymbols`：替换掉连续的空格、换行符和制表符
- `deleteLinks`：删除所有URL和电子邮件地址

**解析方式**（`docAnalyzer`，控制如何提取文档内容，可多选）：

- **文字提取**（`text`）：提取文档中的文本信息，适用于所有文件，必选；
- **OCR解析**（`model`）：基于 OCR 模型统一解析 PDF/Word/PPT 等文档内的全类型内容（含图片中的文字），需指定 `parserModelId`；
- **音频解析**（`asr`）：仅多模态知识库，通过 ASR 模型对音频/视频中的语音转写，需指定 `asrModelId`；
- **图文问答解析**（`multimodal`）：仅多模态知识库，通过图文问答模型理解图片/视频内容，需指定 `multimodalModelId`。

## 请求接口

| Type     | Instructions                                                         |
| -------- | ------------------------------------------------------------ |
| 方法     | Http                                                         |
| 请求URL  | 按照应用实际API根地址，例如：<br />`http://localhost:8081/service/api/openapi/v1/knowledge/doc/import` |
| 调用方式 | 异步调用                                           |
| 字符编码 | UTF-8                                                        |
| 请求类型 | POST                                                         |
| 鉴权方式(header参数) | `Authorization: Bearer {API Key}` |
| 请求格式 | `Content-Type: application/json`              |
| 响应格式 | `Content-Type: application/json`                             |

## 请求参数

| Parameter    | Required | Type   | Instructions                         |
|--------------|----------| ------ |--------------------------------------|
| knowledgeId  | 是        | string   | 知识库id                                |
| docInfoList  | 是        | object array | 上传文档列表                               |
| docImportType | 是        | int | 文档导入类型，固定填 0（文件上传） |
| docSegment   | 是        | object | 文档分段配置                               |
| docAnalyzer  | 是        | string array | 文档解析类型 text / model / asr / multimodal，详见下方说明 |
| parserModelId  | 视情况    | string | 文档解析（OCR/解析模型）的模型uuid；docAnalyzer 含 `model` 时**必填**（接口强制，为空报错） |
| asrModelId  | 视情况    | string | ASR模型uuid；docAnalyzer 含 `asr` 时**必填**（接口强制，为空报错）。上传音频需转写时使用，上传视频可选（用于提取视频中的语音） |
| multimodalModelId  | 视情况    | string | 图文问答（多模态）模型uuid；docAnalyzer 含 `multimodal` 时**必填**（接口强制，为空报错） |
| docPreprocess  | 否        | string array | 文本预处理规则，可传空数组。replaceSymbols：替换掉连续的空格、换行符和制表符；deleteLinks：删除所有URL和电子邮件地址 |
| docMetaData  | 否        | object array | 元数据列表                                |

### docAnalyzer取值说明

- `text`：文字提取（默认，所有方式都需要携带）
- `model`：文档解析（即页面上的"启用OCR解析"），基于 OCR 模型统一解析 PDF/Word/PPT 等文档内全类型内容。`parserModelId` **必填**，为空接口直接报错 `parserModelId can not be empty`
- `asr`：音频解析，仅多模态知识库。`asrModelId` **必填**，为空接口直接报错 `asrModelId can not be empty`
- `multimodal`：图文问答解析，仅多模态知识库。`multimodalModelId` **必填**，为空接口直接报错 `multimodalModelId can not be empty`

> `parserModelId` / `asrModelId` / `multimodalModelId` 填的都是模型的 **uuid**（对外唯一标识，形如 `2004027523746238517` 的数字串，非带连字符的 UUID），可从模型列表相关接口获取。**传入的 uuid 必须是真实存在的模型**，否则接口会报错、导入失败；docAnalyzer 未使用对应解析类型时留空字符串即可。

### docInfoList中详细字段

| Parameter    | Required | Type   | Instructions                     |
|--------------|----------| ------ |------------------------|
| docId   | 是        | string | 文档id，即上传文件API返回的 `fileId`     |
| docName | 是        | string | 文档名称   |
| docUrl  | 否        | string | 文件上传方式无需传，留空即可    |
| docType | 是        | string | 文档后缀，如 `.pdf` / `.docx` / `.zip` / `.tar.gz` / `.mp4` / `.png` / `.mp3`   |
| docSize | 否        | int | 文档大小，单位字节(Byte)   |

#### 字段从前置接口返回值取值对照

`docInfoList` 里的字段不能凭空填写，需从[上传文件API](1.上传文件API.md)的返回值取值，字段名不一一对应，按下表映射：

| docInfoList 字段 | 取值来源（上传文件API 返回的 files 内字段） | 说明 |
|------------------|--------------------------------|------|
| docId   | fileId   | 直接用 fileId 填 docId |
| docName | fileName | 原始文件名 |
| docSize | fileSize | 文件大小(Byte) |
| docType | —（从 fileName 的后缀自行推导） | 取文件后缀，如 `1.docx` → `.docx`；压缩包 `a.tar.gz` → `.tar.gz` |
| docUrl  | 不传（留空） | 文件上传方式无需 docUrl，后端会用 docId 自动从存储中解析文件地址；上传文件API返回的 `filePath` 无需使用 |

### docSegment中详细字段

| Parameter    | Required  | Type   | Instructions                     |
|--------------|-----| ------ |------------------------|
| segmentMethod   | 是 | string | 分段方法 0：通用分段；1：父子分段     |
| segmentType     | 通用分段必填 | string | 分段方式 0：自动分段；1：自定义分段（通用分段不传会报 `segmentType error`）   |
| splitter        | 自定义分段/父子分段必填 | string array | 分段标识（分隔符），如 `["\n\n"]`；父子分段时为父块的分段标识    |
| maxSplitter     | 自定义分段/父子分段必填 | int | 可分割最大值，如 1024；父子分段时为父块的可分割最大值   |
| overlap         | 自定义分段必填 | float32 | 可重叠值，0~1，如 0.2（仅通用分段+自定义分段使用）    |
| subSplitter     | 父子分段必填 | string array | 子块的分段标识，如 `["\n"]`    |
| subMaxSplitter  | 父子分段必填 | int | 子块的可分割最大值，如 200，不能大于 `maxSplitter`（否则报 `subMaxSplitter error`）    |

### docMetaData中详细字段

导入接口只使用以下字段为文档设置元数据；元数据的更新/删除请使用文档元数据相关接口（导入时传的 `metaId`、`option` 等字段不生效）。

| Parameter    | Required | Type   | Instructions                     |
|--------------|----------| ------ |------------------------|
| metaKey       | 是        | string | 元数据key   |
| metaValue     | 是        | string | 元数据值    |
| metaValueType | 是        | string | string，number，time   |
| metaRule      | 否        | string | 正则表达式    |

## 响应参数

| Parameter  | Type     | Instructions   |
| ---- | ------ | ---- |
| code | int    | 状态码，0 表示提交成功  |
| data | null   | 异步接口，固定返回 null；导入进度请通过文档列表/文档导入状态接口查询 |
| msg  | string | 返回信息 |

```shell
    "replaceSymbols"

  "docMetaData": [],

    "segmentMethod": "0",
    "segmentType": "0"
  },

    {
      "docId": "8b4139e0-6fd7-4673-bb21-bb32a9c53f48.docx",
      "docName": "1.docx",
```


## 请求示例-多模态文件上传

仅多模态知识库支持。图片/音频/视频文件同样先通过[上传文件API](1.上传文件API.md)上传取得 `fileId`。上传音频时 `asrModelId` 必填、上传视频时可选（用于提取视频中的语音），使用时在 `docAnalyzer` 中携带 `asr`；上传图片/视频需要图文问答能力时传 `multimodalModelId`（可选）并在 `docAnalyzer` 中携带 `multimodal`。

```shell
curl --location 'http://localhost:8081/service/api/openapi/v1/knowledge/doc/import' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {API Key}' \
--data '{
  "knowledgeId": "2010063921393520640",
  "docImportType": 0,
  "docAnalyzer": [
    "text",
    "asr",
    "multimodal"
  ],
  "docPreprocess": [],
  "docMetaData": [],
  "docSegment": {
    "segmentMethod": "0",
    "segmentType": "0"
  },
  "docInfoList": [
    {
      "docId": "3f2b0d4a-91e2-4f6b-8a17-6a4a2b9a1c55.mp4",
      "docName": "demo.mp4",
      "docType": ".mp4",
      "docSize": 52428800
    },
    {
      "docId": "a1cf2b7e-40d3-4f39-9f1c-2f9b8f7e6d21.png",
      "docName": "pic.png",
      "docType": ".png",
      "docSize": 1048576
    },
    {
      "docId": "e7d80c25-7b64-4b1c-a2ff-08c1d2e3f4a5.mp3",
      "docName": "audio.mp3",
      "docType": ".mp3",
      "docSize": 8388608
    }
  ],
  "parserModelId": "",
  "asrModelId": "2044621459917115392",
  "multimodalModelId": "2011253195170385920"
}'
```
