# 删除子分段API

知识库删除子分段支持删除父子分段文档中指定父分段下的一条或多条子分段。

> 仅父子分段（导入时`segmentMethod`为`1`）的文档支持子分段操作，通用分段文档无子分段。删除父分段请使用删除文档切片API。

## 请求接口

| Type     | Instructions                                                 |
| -------- | ------------------------------------------------------------ |
| 方法     | Http                                                         |
| 请求URL  | 按照应用实际API根地址，例如：<br />`http://localhost:8081/service/api/openapi/v1/knowledge/doc/segment/child/delete` |
| 调用方式 | 同步调用                                                      |
| 字符编码 | UTF-8                                                        |
| 请求类型 | DELETE                                                       |
| 鉴权方式 | `Authorization: Bearer {API Key}` |
| 请求格式 | `Content-Type: application/json`                             |
| 响应格式 | `Content-Type: application/json`                             |

## 请求参数

| Parameter    | Required  | Type   | Instructions                                                 |
|---------------|----| ------ |--------------------------------------------------------------|
| docId | 是  | string | 文档Id，仅支持处理完成状态的文档 |
| parentId | 是  | string | 父分段id，即获取文档分片列表API返回的`contentId` |
| parentChunkNo | 否  | int | 父分段序号，即获取文档分片列表API返回的`contentNum` |
| childChunkNoList | 是  | int array | 待删除的子分段序号列表，序号取获取子分段列表API返回的`childNum`。传入不存在的序号不会报错，但也不会删除任何内容 |

## 响应参数

| Parameter          | Type         | Instructions   |
|--------------------| ------------ |--------------|
| code               | int          | 状态码        |
| data               | object       | 返回数据   |
| msg                | string       | 返回信息       |

## 请求示例

```shell
curl --location --request DELETE 'http://localhost:8081/service/api/openapi/v1/knowledge/doc/segment/child/delete' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {API Key}' \
--data '{
    "docId": "2061726711199830016",
    "parentId": "68d24b24be7778c1e047b4c0e66c355c",
    "parentChunkNo": 1,
    "childChunkNoList": [3, 4]
}'
```

## 响应示例

```json
{
  "code": 0,
  "data": null,
  "msg": ""
}
```

删除后剩余子分段的`childNum`保持原值不变，不会重新编号，后续操作请以获取子分段列表API的返回为准。

## 常见错误码

| Code   | Instructions                                                 |
|--------|--------------------------------------------------------------|
| 145013 | 删除文档分段失败，请稍后重试（如文档非处理完成状态） |
