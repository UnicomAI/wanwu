# 更新子分段API

知识库更新子分段支持修改父子分段文档中指定子分段的内容。一次调用更新一条子分段。多模态知识库的子分段内容中可插入图片markdown（图片地址通过分段图片上传API获取），普通知识库子分段内容不允许包含图片。

> 仅父子分段（导入时`segmentMethod`为`1`）的文档支持子分段操作，通用分段文档无子分段。

## 请求接口

| Type     | Instructions                                                 |
| -------- | ------------------------------------------------------------ |
| 方法     | Http                                                         |
| 请求URL  | 按照应用实际API根地址，例如：<br />`http://localhost:8081/service/api/openapi/v1/knowledge/doc/segment/child/update` |
| 调用方式 | 同步调用                                                      |
| 字符编码 | UTF-8                                                        |
| 请求类型 | POST                                                         |
| 鉴权方式 | `Authorization: Bearer {API Key}` |
| 请求格式 | `Content-Type: application/json`                             |
| 响应格式 | `Content-Type: application/json`                             |

## 请求参数

| Parameter    | Required  | Type   | Instructions                                                 |
|---------------|----| ------ |--------------------------------------------------------------|
| docId | 是  | string | 文档Id，仅支持处理完成状态的文档 |
| parentId | 是  | string | 父分段id，即获取文档分片列表API返回的`contentId` |
| parentChunkNo | 否  | int | 父分段序号，即获取文档分片列表API返回的`contentNum` |
| childChunk | 是  | object | 待更新的子分段，详见下表 |

### childChunk中详细字段

| Parameter    | Required  | Type   | Instructions                                                 |
|---------------|----| ------ |--------------------------------------------------------------|
| chunkNo | 是  | int | 子分段序号，即获取子分段列表API返回的`childNum` |
| content | 是  | string | 更新后的子分段内容，长度不能超过文档配置的最大分段长度；多模态知识库可包含图片markdown（如`![图片名称](图片地址)`），普通知识库不允许 |

## 响应参数

| Parameter          | Type         | Instructions   |
|--------------------| ------------ |--------------|
| code               | int          | 状态码        |
| data               | object       | 返回数据   |
| msg                | string       | 返回信息       |

## 请求示例

```shell
curl --location 'http://localhost:8081/service/api/openapi/v1/knowledge/doc/segment/child/update' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {API Key}' \
--data '{
    "docId": "2061726711199830016",
    "parentId": "68d24b24be7778c1e047b4c0e66c355c",
    "parentChunkNo": 1,
    "childChunk": {
        "chunkNo": 2,
        "content": "这是更新后的子分段内容"
    }
}'
```

## 响应示例

```json
{
  "code": 0,
  "data": null,
  "msg": ""
}
```

## 常见错误码

| Code   | Instructions                                                 |
|--------|--------------------------------------------------------------|
| 145011 | 分段长度超过最大值 |
| 145012 | 更新文档分段失败，请稍后重试（如文档非处理完成状态） |
| 145022 | 当前知识库不支持插入图片，仅多模态知识库可插入图片 |
