# 平台产品介绍

本平台Yes一款面向企业级场景的一站式、商用license友好的Agent开发平台，致力于为企业提供安全、高效、合规的一站式AI解决方案。我们以"技术开放、生态共建"为核心理念，通过整合大语言模型、业务流程自动化等前沿技术，构建了覆盖模型全生命周期管理、MCP、联网检索、Agent快速开发、企业Knowledge Base建设、复杂Workflow编排等完整Features体系的AI工程化平台。平台采用模块化架构设计，支持灵活的Features扩展和二次开发，在确保企业Data安全和隐私保护的同时，大幅降低了AI技术的App门槛。None论Yes中小型企业快速构建智能化App，还Yes大型企业实现复杂业务场景的智能化改造，都能提供强有力的技术支撑，助力企业加速数字化转型进程，实现降本增效和业务创新。



## 核心优势

**License Free：**采用Apache 2.0 License构建宽松生态，彻底解除商业版Permission制，赋予企业自由扩展、二次开发的完整自主权，为企业技术创新提供None边界空间。 

**企业级多租户：**提供多租户账号体系，满足UserData安全隔离、业务弹性扩展等核心需求，解决一些开源平台在多Organization场景下的架构局限。

**高精准RAG：**平台RAGFeatures在性能上实现了显著突破，从多个维度增强模型生成效果，支持多模态检索，利用级联切分算法增强长文本召回匹配度、自适应拆分算法增强知识理解完整性、多路检索融合算法增强检索能力多样性。整体RAG精度较主流开源RAG方案提升20%。

**原生支持MCP：**UserNone需额外安装插件即可调用全量MCPService，标准化Interface协议大幅降低Tools连接成本。平台MCP Square上还整合了100+优质行业MCP Server，方便各行业User快捷调用。

**原生支持联网检索：**User在创建Agent的过程中，None需额外安装Tools插件，即可使用联网检索Service。支持User从百亿级网页中获取知识，涵盖天气、新闻、百科等，提升Agent响应效果。

**Safety Guardrails：**平台支持User自定义敏感词表，Configuration行业敏感词，实时拦截高风险内容的Input和Output，保障内容安全合规。



## Features模块

Model Management： 支持Import LLM、Embedding 和 Rerank 模型，并进行模型推理。
Knowledge Base： 支持Create Knowledge Base，进行知识管理，并提供向量检索、全文检索和混合检索等Features。
MCP 广场： 提供精选推荐的 MCP server，并支持Import自定义 MCP Service。
Safety Guardrails： 支持创建和管理敏感词表，控制模型反馈结果的安全性。
Text QA： 支持创建和管理Text QAApp，并生成 API Interface。
Workflow： 支持创建和管理Workflow，并进行调试和Publish。
Agent： 支持创建和管理Agent，并进行调试和Publish。
App Square： 提供App体验和历史App管理Features。
Settings： 支持个人信息修改、Organization管理、Organization切换和平台Configuration等Features。



## 适用场景

**智能客服：** 提供智能问答、自动回复等Features，提升客服效率和Service质量。
**智能写作：** 辅助生成文案、报告等内容，提高写作效率和质量。
**智能Data分析：** 自动分析Data，生成洞察报告，辅助决策。
**业务流程自动化：** 自动化执行业务流程，提高工作效率。
