# Resource Library

Resource Library集合纳管MCPService和Tools，即选即用。



### MCPService

#### 【ImportMCP】

![image-20251030101444123](assets/image-20251030101444123.png)

点击“Import”，关联自己的MCP，可支持在Workflow中使用。User需填写ServiceName、Service来源、FeaturesDescription、MCP ServerURL。点击“获取MCPTools”，获取Success后，将显示可用Interface。点击“ConfirmPublish”，即可在平台上查看每个Tools的详细内容。

![image-20250725150237535](assets/image-20250725150237535.png)

![image-20250725150712915](assets/image-20250725150712915.png)



#### 【创建MCP】

平台支持User绑定Tools，创建自己的MCP Server，并对外提供Service。这里可以看到你创建的所有 MCP server，以及他们管理的Tools数量。

![image-20251030101317123](assets/image-20251030101317123.png)

**1、创建MCP**

点击**”创建MCP“**，即可进入创建页面，User可ConfigurationMCP Server的图标，Name、Description。

![image-20251030102453389](assets/image-20251030102453389.png)

**2、查看Service地址**

点击“确定”，可进入Edit界面。平台提供SSE URL和Streamable HTTP两类Service地址，及对应的请求Example。

![image-20251030103240964](assets/image-20251030103240964.png)

**3、绑定App**

**3.1 关联已有App**

点击**“关联”**，可绑定User自定义Tools。自定义Tools可在【Resource Library】-【Tools】-【自定义】模块进行添加。选择需要的Tools，点击**“添加”**。

![image-20251030103620363](assets/image-20251030103620363.png)

![image-20251030104258007](assets/image-20251030104258007.png)

添加后，User可EditTools对外Output的显示Name（仅限英文）和Description。

![image-20251030105130368](assets/image-20251030105130368.png)

**3.2 创建App**

点击**“创建”**，可新建Tools。InputName、选择API鉴权方式、填写Schema，可自动解析出可用API。User可根据需要，勾选想要绑定的API。点击**“确定”**，即可Save。添加后，User可EditTools对外Output的显示Name（仅限英文）和Description。

![image-20251030105342396](assets/image-20251030105342396.png)

![image-20251030105620217](assets/image-20251030105620217.png)

**4、API密钥**

点击“获取API密钥”，可生成密钥。请您妥善保管密钥。

![image-20251030110141838](assets/image-20251030110141838.png)





### Tools

Tools分为内置Tools和自定义Tools。

- **内置Tools**

​	平台内置多款Tools，User可通过ConfigurationAPI Key直接使用。点击内置Tools可查看相关介绍以及参数解析。

![image-20250926133806677](assets/image-20250926133806677.png)

![image-20250926134001052](assets/image-20250926134001052.png)



- **自定义Tools**

点击“创建自定义Tools”，可Link第三方开源APIInterface，后续可在Agent中进行Tools关联。选择Interface样例或自行InputSchema后，即可获得api参数。

![image-20250926133827991](assets/image-20250926133827991.png)

![image-20250822101724565](assets/image-20250822101724565.png)

**【API身份认证鉴权】**

支持3种鉴权方式：None需鉴权、Request Header、Query参数。

![image-20251107110929180](assets/image-20251107110929180.png)



### 提示词

提供提示词模板Configuration界面，User可Add提示词模板。或点击查看现有的提示词模板。平台在“Template Square”提供了丰富的提示词模板库，User可进行复制使用。

![image-20251107111020792](assets/image-20251107111020792.png)

![image-20251107111123907](assets/image-20251107111123907.png)

针对已创建的提示词模板，还可进行提示词优化。优化后的提示词，可直接替换原有提示词。
