### 2. Organization Management

This module can perform unified management of organizations, users, and roles.

- **1) Organization Management**

  - **Organization View**
    
    Administrators can view the situation of all sub-organizations within this organization, and can edit, delete, deactivate, and add sub-organizations.
    
    Click "Edit" to change the sub-organization name.

![image-20250725160802725](image-20250725160802725.png)

![image-20250912111717381](image-20250912111717381.png)

  - **Add Organization**
    
    Click "Add Organization" to set the organization name.
    
    Click "Confirm" to complete adding the sub-organization.
    
    When users create subordinate organizations, the system by default creates a role like "Organization Administrator" in the new organization, which by default has all permissions of the new organization; at the same time, the user by default joins the new organization and corresponds to that role.

![image-20250725160851944](image-20250725160851944.png)

- **2) Role Management**

  - **Role View**
    
    Administrators can view the situation of all roles within this organization, and can edit, delete, deactivate, and add roles.
    
    The "Organization Administrator" role cannot be deleted or deactivated.
    
    The same user can be in multiple organizations.
    
    Click "Edit" to change the role name and menu permissions.

![image-20250725160945751](image-20250725160945751.png)

![image-20250725161003425](image-20250725161003425.png)

  - **Add Role**
    
    Click "Add Role" to set the role name and menu permissions.
    
    Click "Confirm" to complete adding the role.
    
    When users create a new role, the permission set cannot exceed the permission set of the user's current corresponding role.

![image-20250725161040355](image-20250725161040355.png)

- **3) User Management**

  - **User View**
    
    Organization administrators can view the situation of all users within this organization, and can edit, delete, reset passwords, add accounts, and invite users.
    
    System administrators can view the situation of all users within this system, and can edit, delete, and reset passwords.
    
    Click "Edit" to change the user's unit, phone, role, and email.

![image-20250912111607162](image-20250912111607162.png)

![image-20250725161124698](image-20250725161124698.png)

  - **Add Account**
    
    Click "Add Account" to set the username, password, unit, phone, role, and email.
    
    Click "Confirm" to complete adding the user.
    
    A user assigned to an organization may not correspond to any role.
    
    The organization the user belongs to, if the corresponding role has user creation permission, then the user creating a new user must by default belong to that organization.

![image-20250725161221993](image-20250725161221993.png)

![image-20250725161315968](image-20250725161315968.png)

  - **Invite Users**
    
    Click "Invite Users" to invite specific users.
    
    Administrators can invite any users not in this organization under the system, and invited users automatically join this organization.

![image-20250725161439433](image-20250725161439433.png)

### 3. Organization Switching

The platform supports multi-tenancy. Users can perform organization switching, view applications created under different organizations, and perform editing and usage.

![image-20250725161524608](image-20250725161524608.png)

To facilitate user secondary development, a visual frontend interface modification entry is provided, supporting users to modify tag pages, login pages, and platform configuration.
