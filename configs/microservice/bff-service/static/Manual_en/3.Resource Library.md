# Resource Library

Resource Library manages MCP services and tools, ready to use immediately.

### MCP Services

#### [Import MCP]

![image-20251030101444123](image-20251030101444123.png)

Click "Import" to associate your own MCP, which can be used in workflows.

Users need to fill in the service name, service source, feature description, and MCP server URL.

Click "Get MCP Tools". After successful acquisition, available interfaces will be displayed.

Click "Confirm Publish" to view the detailed content of each tool on the platform.

![image-20250725150237535](image-20250725150237535.png)

![image-20250725150712915](image-20250725150712915.png)

#### [Create MCP]

The platform supports users binding tools, creating their own MCP servers, and providing services externally.

Here you can see all the MCP servers you created and their management tool counts.

![image-20251030101317123](image-20251030101317123.png)

- **1. Create MCP**

  Click **"Create MCP"** to enter the creation page where users can configure the MCP server icon, name, and description.

![image-20251030102453389](image-20251030102453389.png)

- **2. View Service Address**

  Click "OK" to enter the editing interface.

  The platform provides two types of service addresses: SSE URL and Streamable HTTP, along with corresponding request examples.

![image-20251030103240964](image-20251030103240964.png)

- **3. Bind Application**

  - **3.1 Associate Existing App**
    
    Click **"Associate"** to bind user-defined tools.
    
    User-defined tools can be added in the [Resource Library]-[Tools]-[Custom] module.
    
    Select the required tools and click **"Add"**.

![image-20251030103620363](image-20251030103620363.png)

![image-20251030104258007](image-20251030104258007.png)

    After adding, users can edit the tool's external display name (English only) and description.

![image-20251030105130368](image-20251030105130368.png)

  - **3. Create App**
    
    Click **"Create"** to create new tools.
    
    Input name, select API authentication method, and fill in schema to automatically parse available APIs.
    
    Users can select the APIs they want to bind as needed.
    
    Click **"OK"** to save.
    
    After adding, users can edit the tool's external display name (English only) and description.

![image-20251030105342396](image-20251030105342396.png)

![image-20251030105620217](image-20251030105620217.png)

- **4. API Key**

  Click "Get API Key" to generate the key.
  
  Please keep the key secure.

![image-20251030110141838](image-20251030110141838.png)

### Tools

Tools are divided into built-in tools and custom tools.

- **Built-in Tools**

  The platform has multiple built-in tools. Users can use them directly by configuring API keys.
  
  Click on built-in tools to view related introductions and parameter parsing.

![image-20250926133806677](image-20250926133806677.png)

![image-20250926134001052](image-20250926134001052.png)

- **Custom Tools**

  Click "Create Custom Tools" to link third-party open-source API interfaces, which can later be associated with tools in agents.
  
  After selecting interface samples or manually inputting schema, you can obtain API parameters.

![image-20250926133827991](image-20250926133827991.png)

![image-20250822101724565](image-20250822101724565.png)

- **[API Identity Authentication]**

  Supports 3 authentication methods: no authentication required, request header, and query parameters.

![image-20251107110929180](image-20251107110929180.png)

### Prompts

Provides prompt template configuration interface where users can add prompt templates or click to view existing prompt templates.

The platform provides a rich prompt template library in "Template Square" where users can perform copy and use.

![image-20251107111020792](image-20251107111020792.png)

![image-20251107111123907](image-20251107111123907.png)

For created prompt templates, prompt optimization can also be performed.

Optimized prompts can directly replace original prompts.
