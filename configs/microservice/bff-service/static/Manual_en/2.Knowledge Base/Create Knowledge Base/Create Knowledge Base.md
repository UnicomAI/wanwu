# Create Knowledge Base

## New Knowledge Base

If users want to use RAG features, they need to first create a Knowledge Base and associate an Embedding model.

The embedding model must be uploaded in advance in the Model Management module.

Users can also perform tag settings to facilitate knowledge base filtering and categorization.

(For created but unfilled content tags, you can quickly delete using the backspace key)
